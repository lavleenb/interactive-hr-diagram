## What is a Hertzprung-Russell diagram? 
Often described as the periodic table for astronomers, the Hertzprung-Russell diagram plots the luminosity of stars against their temperature, revealing many important relationships between the two properties. 
Some important star groups become visible, including the main sequence stars along the diagonal trend of the graph, the red giants, white dwarves, and more. 
This diagram is also used to trace and study the lifecycle of stars of various masses. 

## What is the purpose of this project?
I wanted to create an interactive scatterplot showcasing data collected from my own backyard stargazing. The user can easily zoom in and reference the information of whichever star they are interested. I also wanted to create an easy way for the user to follow the lifecycle of any star they click on. 
The main purpose of this project is to educate the user about star lifecycles, and the various different types of stars that exist. 

## What did I learn? 
I had to become familiar with the javascript Plotly library to allow the diagram to come to life. Along with this, I picked up on ADQL, the query language used for astronomical data, to be able to easily access and reference data from Gaia. 
For the time being, I am using my own backyard observations and backing them up with info from Wikipeida using a Python scraper built with Beautiful Soup. 

## Next steps? 
I hope to continue learning ADQL and querying the Gaia database for more accurate results from a trusted source. I also plan to include more ways for the user to interact with the app. This includes adding stars to see where they'd appear on the graph and exploring star lifecycles based on their starting mass.
